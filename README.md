# 🛒 Lista de Compras - Android

<img width="1024" height="500" alt="Gemini_Generated_Image_x7dixsx7dixsx7di" src="https://github.com/user-attachments/assets/b1f5b58e-73d5-43fe-bf4e-8e341c5f0395" />

Um aplicativo Android simples e funcional para gerenciar listas de compras. Ideal para quem quer manter o controle de suas compras de forma rápida, intuitiva e prática.

## ✨ Funcionalidades

- ✅ Adicionar, editar e remover itens da lista de compras  
- 📝 Marcar itens como comprados  
- 📦 Organização por categorias (ex: Hortifruti, Padaria, Limpeza, etc.)  
- 🔄 Salvar listas reutilizáveis para futuras compras  
- 🌙 Suporte a tema claro e escuro

## 📱 Tecnologias Utilizadas

- Kotlin  
- Jetpack Compose
- Room (persistência local)  
- ViewModel + LiveData/StateFlow  
- Material Design 3  
- Firebase Authentication/Firestore
- Uso de biblioteca local encapsulando várias bibliotecas e utilitários [Toolkit]
